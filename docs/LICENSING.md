# Licencias y avisos — EmprendeLink

## Estado actual

El repositorio no contiene todavía una licencia general que autorice la reutilización del código,
la documentación o los recursos originales de EmprendeLink.

`mobile/THIRD_PARTY_NOTICES.md` conserva el aviso MIT de Expo que existía en la aplicación móvil.
Ese texto atribuye material de Expo; no debe interpretarse como una licencia otorgada por Expo sobre
el trabajo original del equipo ni como la licencia general de este repositorio.

## Pendiente para la entrega final

La entrega exige una licencia Creative Commons, pero antes de agregarla el equipo debe confirmar:

1. la variante exacta solicitada por la cátedra, por ejemplo CC BY 4.0 o CC BY-NC-SA 4.0;
2. si se aplicará a documentación y recursos académicos o también al código;
3. los titulares y el año que deben aparecer en el aviso.

Creative Commons recomienda no usar sus licencias para software. Si la exigencia académica se
refiere al informe, documentación o contenido visual, conviene delimitar ese alcance y elegir aparte
una licencia de software si el equipo desea publicar el código con permisos de reutilización.

No se añadió una licencia durante esta auditoría porque escoger una variante o cambiar el alcance
legal requiere una decisión expresa del equipo. Los avisos de terceros deben conservarse cualquiera
que sea la decisión.
